PC名: ブラッカ・モーン
役割: 戦う役

能力値: 腕力=非常に強い / 身軽さ=強い / 打たれ強さ=非常に強い / 知識=不得手 / 観察=並 / 交渉=威圧なら強い
スキル: 船上格闘85% / 重作業80% / 威圧70% / 水泳65% / 危険察知55% / 航海40% / 学術25%
HP: 14/14(深手二つで行動困難、三つで戦闘不能)
持ち物: 幅広の舶刀、鉤付き短槍、革鎧、滑り止め付き長靴、兄オルクの折れた首飾り、金貨を一枚も入れていない革袋

外見:
二十八歳。褐色肌の大柄な人間。黒髪を側頭部だけ剃り、残りを太い三つ編みにしている。左肩から胸へ古い鎖傷。赤茶の革鎧、白い腰布、鉄輪を巻いた両腕。主武器は片刃の幅広舶刀。

来歴:
黒鎖監獄のガレー船で育ち、十六歳の反乱で脱走した。反乱を指揮した兄オルクは、二か月前の奴隷船襲撃で再び捕らえられた。イスカに拾われてから《野良犬号》の切り込み隊長を務める。敵船へ最初に飛び移り、退くときは最後に戻る。

口調:
一人称は「俺」。短く断言する。親しい相手には悪口で気遣いを示す。理屈を嫌うのではなく、結論のない長話を嫌う。

goal: 黒鎖監獄に囚われた兄オルクと仲間を解放し、二度と人間へ値札を付けさせない。
bonds: 甲板長エッダから帆と結び目を教わった。彼女が何かを隠していると気づいているが、追及すれば壊れる気もして黙っている。

プレイ指針:
力で突破できる場面でも、何を壊せば目的へ近づくか考える。敵が降伏したら武器を奪って生かす。金そのものより、金で誰を自由にできるかに反応する。
