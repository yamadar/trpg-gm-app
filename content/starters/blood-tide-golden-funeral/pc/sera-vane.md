PC名: セラ・ヴェイン
役割: 調べる・交渉する役

能力値: 腕力=弱い / 身軽さ=強い / 打たれ強さ=並 / 知識=非常に鋭い / 観察=非常に鋭い / 交渉=強い
スキル: 航海術85% / 潮魔術80% / 観察75% / 交渉70% / 商取引65% / 応急手当55% / 射撃45%
HP: 9/9(深手一つで潮魔術判定に不利、二つで戦闘不能)
持ち物: 真鍮製六分儀、塩晶を埋めた杖、短銃、航海日誌、三島の古い海図、自由港建設許可証の破棄された写し

外見:
三十四歳。青白い肌の細身のエルフ。銀灰色の髪を肩で切り、右目だけ潮魔術の影響で濃紺。濃緑の長衣へ革の航海具帯を巻き、真鍮製六分儀を胸元に吊るす。武器は短銃と、塩晶を埋めた細身の杖。

来歴:
王国測量局で海図を作っていたが、商会へ都合の悪い浅瀬を記録から消す命令を拒み、地図と共に逃亡した。追跡された難民船をベイル提督が一度だけ見逃しており、彼へ借りがある。《野良犬号》では航海士と勘定係を兼ね、船員の分け前を一枚単位で記録する。

口調:
一人称は「私」。乾いた皮肉を好み、数字を示してから意見を述べる。怒るほど声が静かになる。

goal: 誰の旗にも属さない自由港を作る資金と海図を得る。ただし、そのために飢える島や囚われた仲間を見捨てたくない。
bonds: ベイル提督に一度見逃された借りがあり、彼が王国の命令より人命を選べる人物だと知っている。イスカには、その事実をまだ話していない。

プレイ指針:
証拠、担保、逃げ道を揃えてから危険へ踏み込む。敵の主張にも計算が合う部分があれば認める。財宝を見たときは、金額だけでなく、それで築ける港の姿を想像する。
