# 義体の記憶

## シナリオ概要

闇市に一本の中古義手が流れた。型は三世代前、左腕、値札は相場の三割。買い手はすぐについたが、その晩のうちに露店へ戻された。

理由は接続してすぐ分かる。神経を繋ぐと、使っていない記憶が再生されるのだ。知らない部屋、知らない声、知らない手続き。前の持ち主の残留記憶ならまだ話は分かるが、再生される記憶の中で、その人物は両腕とも自分のものとして動かしている。つまりこの記憶は「義手を着けていた誰か」のものではない。

義手はいま闇市の露店に戻され、値札を外されて置かれている。売り手は困っている。返品は受けないが、そのまま次の客に売るのも気が進まないという。

## 導入

高架下、雨の跳ね返る夜。露店の主人が、布をかけた左腕をカウンターの下から出す。「これ、あんたらの商売のほうだろ」と言って、接続端子を上に向けて置く。触れば分かる、とだけ言って、あとは黙る。

## 章1: 出所を辿る

- 義手のシリアルは削られているが、内部のロットタグまでは消されていない。蒼洋重工の製造ラインの製品である
- 露店の主人は仕入れ先を渋る。三軒挟んだ先に情報屋のミミがおり、彼女に行き着くまでにいくつかの貸し借りが要る
- 検問のゲート記録を当たると、この義手の識別信号は一度も橋を渡っていない。特区の中で作られ、特区の中を回っただけの腕である
- 分岐条件: `flags.traced_the_arm == true` → 義手が中古市場に出る前、一度も個人に登録されていなかったことが判明する。誰の腕でもないまま出荷された腕だと分かる

## 章2: 分解と読み出し

- 認可外の診療所へ持ち込めば、外装を割って記憶格納部を直接読める。企業の正規窓口へ出せば読めるが、その時点で義手は戻ってこない
- 分解の最中、義手は接続していないのに一度だけ指を握る。工程を止めるか続けるかで、読み出せる量が変わる
- 読み出したログには、記憶の断片と一緒に書き込み日時が並んでいる。日時はすべて製造工程の期間内に収まっている
- 分岐条件: `flags.read_the_log == true` → 記憶が「前の持ち主が残したもの」ではなく、外から書き込まれたものだと確定する。書き込み元の工程番号も読める

## 章3: 探すか、消すか

- 記憶の中の声と部屋の特徴から、その人物を特定して会いに行くことができる。会えば、その人物は自分の記憶が出回っていることを知らないまま生きている
- あるいはログを消し、義手を分解して部品に戻し、この件をなかったことにできる。誰も傷つかず、誰も知らないままになる
- 探す場合、情報屋のミミと特区警備のハントが同時に動く。どちらもPCより先に相手へ辿り着こうとしており、二人の目的は同じではない
- どちらを選んでも、義手が一本だけということはありえない。同じ工程で出た腕は他にもある

## GM専用情報

- **再生される記憶は前の持ち主のものではない。** 義体の製造ラインで、動作確認用のテストデータとして書き込まれたものである。神経接続の応答を検証するには本物の記憶波形が要るため、実在の人物のスキャンがそのまま使われた。その人物は同意していないし、スキャンされたことも知らない
- **情報屋ミミは記憶の主の身内である。** 妹のスキャンデータが検査の名目で採られたことを掴み、証拠を表に出すために、自分でこの義手を闇市へ流した。誰かが接続して騒ぎになるのを待っていた。PCが辿り着くのは偶然ではなく、彼女が仕込んだ経路の終点である
- **特区警備のハントは企業側の回収担当だが、この件を上に報告していない。** 回収指示は受けたが、報告書の下書きを三週間書き直し続けている。彼が黙っているのは正義感からではなく、報告した瞬間に自分も工程の一部として記録されると分かっているからである
- 開示の順序: 章1で「誰にも登録されていない腕」という異常、章2で記憶が書き込まれたものだという事実、章3で初めてミミの動機とハントの沈黙
- 判定の見どころ: 闇市で仕入れ先を割らせる交渉 / 検問のゲート記録への侵入 / 分解工程を止めずに読み切る手技 / ミミの筋書きに乗っているかどうかを見抜く場面
- 失敗の代償の目安: 時間を失う(先にハントが動く)/ 痕跡が残る(蒼洋重工の監査が動き出す)/ 義手そのものを壊してしまい、証拠が記憶の中だけになる
