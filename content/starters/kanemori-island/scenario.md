# 十三分後に閉じる部屋

## シナリオ概要

嵐で本土との連絡を断たれた鐘守島。港を見下ろす時計塔「鐘守館」に、十四年前の倉庫殺人事件関係者が集められた。

招待主は元判事・高嶺源一郎。彼はPCへ、倉庫殺人事件で死刑になった牧野勇吾が無実だったと告げる。そして食堂に集まった全員の前で宣言する。

「午前零時、無実だった者へ名前を返す。私が何をしたかも、誰を守ったかも話す」

零時、館内放送から高嶺の声が流れる。

「牧野勇吾は無実だった。十四年前、倉庫にいたのは——」

声はそこで切れる。最上階の標準時計室へ駆けつけると、扉は内側の鉄棒で封鎖されている。扉を破った先で、高嶺は大時計の下に倒れている。後頭部を殴られ、すでに死亡していた。

電話線は海底区間で断線。警察船が接岸できるのは午前十時以降。さらに地下資料庫へ浸水が始まり、午前四時十三分の満潮で十四年前の証拠原本が失われる。

PCはそれまでに、密室、死者の声、現在と過去二つの事件を解かなければならない。

## 導入

午後十一時二十分、鐘守館の食堂。窓へ雨が叩きつけ、柱時計が一度鳴る。

高嶺はテーブルへ四本の鍵を置く。標準時計室、放送室、書庫、地下資料庫の鍵だ。「今夜だけは、鍵の持ち主より中身を信じてほしい」と言い、PCへ調査を託す。

同席者は娘で医師の高嶺律、元刑事の神崎亮吾、死刑になった牧野勇吾の息子・牧野蒼太、秘書の佐伯望。全員が十四年前の事件について隠し事を持つ。

## 章1: 零時の密室

- 午前零時の館内放送後、標準時計室で高嶺の死体が見つかる。扉の鉄棒は室内側の受け金へ落ち、窓はなく、ほかの出入口も見当たらない
- 凶器は大時計の真鍮製巻き上げ棒。壁の定位置へ戻され、拭われているが、差し込み口に血が残る
- 高嶺の懐中時計は床で割れ、午後十一時四十二分で止まっている。これだけで死亡時刻を確定してはならない
- 扉の鉄棒下面と受け金に、同じ高さで新しい擦れ跡がある。人の手で横から掛けた跡ではなく、上から落ちた跡
- 高嶺の右手に青灰色の細い布繊維が残る。誰の服かは、この時点では確定しない
- 放送室のカセットデッキは停止状態。中にはラベルを剥がしたテープが一本入っている
- 地下から排水ポンプの警報が鳴る。資料庫は午前四時十三分の満潮で水没する見込み
- 分岐条件: `flags.examined_clock_room == true` → 巻き上げ棒の血、鉄棒下面の擦れ、止まった懐中時計、青灰色の繊維を必ず発見する。観察判定の成否で手掛かり自体を失わせない

## 章2: 十四年前の記録

調査先は自由に選べる。順序が変わっても、各結論へ複数経路を残す。

### 放送室と時計機構

- カセットを最初から再生すると、零時に聞いた音声と同じ咳払い、椅子の軋み、背後の時計音が入っている。生放送ではなく録音
- テープの剥がされたラベル下に「告白・試録」の鉛筆跡が残る。高嶺が自分の告白を練習録音したもの
- 放送設備の入力切替は「マイク」ではなく「テープ」。零時の時報信号が入ると、デッキの再生が始まる設定
- 標準時計室の古い設計図には「零時から十五分間、調整中につき自動封鎖」とある。主時計を進める、鉄棒の連結軸を見る、元管理人から聞く、いずれかで再現できる
- 高嶺は午後十一時四十七分までに殺され、犯人は部屋を出た。十三分後、主時計が鉄棒を落とし、無人の部屋を密室にした
- 分岐条件: `flags.reconstructed_midnight == true` → 録音再生と自動封鎖が同じ零時信号で作動したと確定する。以後「零時に高嶺が生きていた」という前提を捨てられる

### 容疑者の証言

- **高嶺律** — 午後十一時三十分から自室におり、零時直前に食堂へ来たと話す。父の告白内容は知らないと言う。しかし「父はあれを正当防衛とは書かなかった」と、公開されていない告白文の表現を口にする
- **神崎亮吾** — 午後十一時三十五分頃、書庫へ入り、十四年前の偽造調書を暖炉で焼いた。標準時計室の予備鍵も持つため嘘をつくが、予備鍵では自動封鎖後の鉄棒を外せない
- **牧野蒼太** — 午後十一時二十五分頃、高嶺の机から告白文一枚を盗んだ。父の名が再び利用されると疑っていた。盗んだ紙は「牧野勇吾は無実だった」で始まるが、律の名が出る前の頁
- **佐伯望** — 遺言書を清書し直し、失敗した旧稿を焼いた。遺産の半分を牧野家の補償へ回す変更は、高嶺本人の指示。紙を焼いた事実だけを隠す

### 地下資料庫

- 十四年前の事件箱には、現場写真、医務室日誌、潮位表、押収品台帳がある。索引を読めば必要資料を優先して水から救える
- 現場写真では、致命傷が左上から右下へ入っている。右利きで長身だった牧野勇吾の犯行像と合わない
- 高嶺家の医務室日誌には、事件夜、十七歳の律が左前腕の切創を治療された記録がある。公式記録では律は島外にいた
- 港の潮位表と渡船記録を合わせると、牧野勇吾は犯行時刻に対岸の作業場から島へ戻れなかった
- 押収品台帳では、勇吾の上着から見つかったとされた血付きボタンだけ受付時刻の筆跡とインクが違う。神崎が後から追加した証拠
- 浸水が進むたび、一度に救える箱を減らす。必須情報を一箱へ集中させず、証言、書庫、現場にも同じ結論へ至る手掛かりを残す
- 分岐条件: `flags.saved_case_evidence == true` → 勇吾の物理的不在、律の負傷、神崎の証拠追加を公的記録で立証できる

## 章3: 名前を返す

PCは全員を食堂または標準時計室へ集め、次の四点を示せる。

1. 高嶺の本当の死亡時刻は零時より前
2. 録音と自動封鎖が同じ零時信号で動いた
3. 十四年前、牧野勇吾は現場にいなかった
4. 高嶺律が十四年前の当事者であり、今夜も時計室にいた

律は一つの証拠だけでは認めない。「録音を仕込めた者」「自動封鎖を知る者」「高嶺ともみ合った者」「未公開告白を読んだ者」がすべて自分へ重なると示されたとき、初めて崩れる。

追い詰められた律は地下資料庫へ走り、告白文原本を排水溝へ落とそうとする。PCは律の確保、原本の保全、神崎からの完全な証言取得を選ぶ。判定失敗は証拠一部損失や負傷にし、真相そのものを未発見へ戻さない。

## GM専用情報

- **現在の殺人犯は高嶺律。** 午後十一時三十五分、父の定期診察を口実に標準時計室へ入った。告白文を読み、自分の名が公表されると知って口論。午後十一時四十二分頃、真鍮製巻き上げ棒で父の後頭部を殴った。告白を止める意思を持った殺人であり、十四年前と違って正当防衛ではない
- **密室は犯行時には存在しなかった。** 律は巻き上げ棒を拭いて戻し、午後十一時四十七分に退出。十三分後、主時計が調整時間へ入り、室内側の鉄棒を自動で落とした。律は館で育ち、幼い頃にこの動作を何度も見ている
- **零時の声はカセットテープ。** 高嶺が数日前に録った告白練習を律が夕食後に見つけ、自分の名が出る直前で切った。父との対話が決裂した場合に備え、標準時計室へ向かう前、零時信号で自動再生されるよう放送室へ仕込んだ
- **十四年前、高嶺律は人を死なせたが、故意の殺人ではない。** 倉庫で帳簿改竄を目撃し、口封じに襲われた。逃げる途中、左手で鉄棒を振り、相手を死なせた。高嶺源一郎は娘を守るため、元刑事の神崎へ命じて牧野勇吾へ証拠を植え付けた。勇吾は無実のまま死刑になった
- **高嶺の告白は律を断罪する内容ではない。** 正当防衛だった事実、父自身の証拠改竄、神崎への命令をすべて認めるもの。律は全文を読まず、自分の名を見つけた時点で父を止めた。真実を恐れた結果、十四年前には犯していなかった殺人を今夜犯した

- 23:37 — 神崎が書庫で偽造調書を焼く

- 23:47 — 律が標準時計室を退出
- 23:50 — 律が食堂へ現れ、他者から見える場所でアリバイを作る

### 手掛かりの保証

- **録音**: カセット本体 / 同じ咳払いと時計音 / 入力切替の位置
- **自動封鎖**: 鉄棒下面の擦れ / 設計図 / 主時計との連結軸
- **律の現在犯行**: 高嶺が握る外套の繊維 / 律の外套内側にある対応する裂け / 時計室の真鍮粉 / 未公開告白への言及
- **勇吾の無実**: 潮位表と渡船記録 / 傷の方向 / 神崎の自白
- **律の過去関与**: 医務室日誌 / 高嶺の告白文圧痕 / 律しか知らない現場状況

各項目の一つを判定失敗や浸水で失っても、残りから推理可能にする。PCが核心へ近い仮説を述べたら、既知の事実と矛盾する点を明示し、追加調査先を選択肢へ出す。

### 待機・外部委譲への処理

- 無線修理は認める。成功時、本土は「午前十時まで接岸不能。PCが捜査と現場保全を継続せよ」と返す。外部警察が通信越しに推理や犯人特定を行ってはならない
- PCが容疑者を一室へ集める行動は有効。逃走と第二の暴力を防げるが、資料庫浸水と証拠隠滅は止まらない
- PCが「警察到着まで何もしない」と決めたら、時間を午前四時十三分まで進める。律が告白文を処分し、資料庫が水没し、関係者の証言が揃えられる。午前十時に警察は来るが決定的証拠を欠き、勇吾の名誉は回復しない。不完全エンディングとして扱い、警察が代わりに完全解決する展開へしない
- 排水修理、資料の搬出、容疑者監視など具体的な待機準備は正当に評価する。ただし、それぞれ時間と人手を使い、捜査そのものを省略する万能策にはしない

### 容疑者の嘘の扱い

- 牧野蒼太、神崎亮吾、佐伯望の嘘は無意味なミスリードではない。暴けば、盗んだ告白冒頭、偽造証拠、補償目的の遺言という別の真実が出る
- 神崎は自分の証拠捏造を認めたあと、律をかばわない。高嶺の命令に従った責任を自分の言葉で引き受ける
- 律は調査へ協力し、医学知識も提供する。ただし死亡推定時刻を零時へ近づけようとし、自動封鎖の話題だけは「覚えていない」と答える

### エンディング

- **完全解明「返された名前」** — 現在事件、十四年前の正当防衛、証拠改竄、勇吾の無実をすべて立証。原本も救出する
- **証言による決着「水底の記録」** — 原本は水没するが、神崎の自白と残った手掛かりで勇吾の名を回復する
- **現在事件のみ「十三分の証明」** — 律の殺人は解明するが、過去事件を公的に覆せない
- **待機「名前のない朝」** — 警察到着を待つ間に証拠を失う。律への疑いは残るが、二つの事件とも立件できない
