# 朱雀大路の百鬼

## シナリオ概要

先月から、朱雀大路を渡る百鬼夜行の列を見たという者が続けて出ている。それ自体は都では珍しくない。珍しいのは証言の中身のほうだった。

列の半ばあたりに、生きた人間が一人、混ざって歩いているという。裸足で、白い袿を着て、異形に挟まれながら、俯きもせずに歩いている。それを見た者が三人おり、三人とも別の夜に、同じ背格好の女を見たと言う。

陰陽寮は「見間違い」として片付けたがっており、検非違使庁は「連れ去りなら人の事件だ」と言っている。どちらの言い分でも、PCたちは夜の朱雀大路へ出ることになる。

## 導入

暮れ方の陰陽寮の一室。届いた三通の証言書と、消し線の入った暦。上役は「確かめてこい、ただし騒ぎにするな」とだけ言い、誰の家の話かは口にしない。

## 章1: 証言と経路

- 三人の目撃者は身分も住まいも異なるが、列を見た時刻はいずれも丑の刻に近い
- 三つの証言を地図の上に置くと、列は羅城門から北へ、朱雀大路をまっすぐ進んでいる。途中で一度も曲がらない
- 分岐条件: `flags.heard_the_witness == true` → 三人目の目撃者(荷車引き)から、女が「見られていることに気づいて、こちらを見返した」という一点が引き出せる

## 章2: 羅城門の夜

- 羅城門の下で夜を明かせば、列が北へ向けて出るところに立ち会える。門の脇には、いつからそこにいるのか分からない老爺が座っている
- 老爺は訊けば答える。ただし答えるのは訊かれたことだけで、それ以上は一言も足さない
- 分岐条件: `flags.watched_at_rajomon == true` → 列の中の女の顔が確認でき、装束と髪の結い方から、どの家の姫かの見当がつく

## 章3: 引き戻すか、行かせるか

- 女を列から引き戻すには、名を呼ぶ必要がある。ただし都の理では、名を呼ぶことは術が通るということでもある
- 行かせると決めるなら、家にはどう報告するかを決めなければならない。真実を書けばその家の事情が表沙汰になる
- 引き戻した場合の代償は、章3の途中まで明かされない。老爺は訊かれれば答えるが、PCがその問いに辿り着くかどうかは分からない

## GM専用情報

- **列を歩いているのは北の対の姫であり、自分から加わった。** 攫われたのでも術にかけられたのでもない。家に戻されることのほうが耐えられなかったのであって、列は彼女にとって逃げ道だった
- **羅城門の老爺は人ではない。** 門そのものが人の姿を取っている。嘘は一切つかないが、聞かれないことは答えない。「代わりが要る」という肝心の一点も、PCが正面から訊くまで口にしない
- **姫を引き戻せば、代わりに誰かが列に加わらなければならない。** 数は合っていなければならず、それが門の側の唯一の条件である。PC自身でもよいし、他の誰かでもよい。門はどちらでも構わない
- 開示の順序: 章1で「連れ去りではないかもしれない」という違和感、章2で女の身元、章3で自ら加わったという事実と、引き戻しの代償
- 判定の見どころ: 目撃者ごとに違う身分に合わせた聞き込み / 装束と髪型から家を特定する知識 / 羅城門で夜を明かす胆力 / 老爺への問いの立て方(訊き方そのものが判定になる)
- SANチェックの主な機会: 列が門から出てくる瞬間 / 女が列の中からこちらを見返したとき / 彼女が自分の意志で歩いていると理解したとき / 代償の条件を聞かされたとき
