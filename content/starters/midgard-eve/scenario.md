# ヘイムダルの角笛

## シナリオ概要

虹の橋の番人ヘイムダルの角笛が、橋のたもとから消えた。角笛は終わりの始まりを全世界へ告げるためのもので、鳴れば誰もが同時にそれを知る。

問題は、角笛が失われても終わりが来ないわけではないことだ。角笛の鳴らないラグナロクは「来ない」のではなく、「予告なしに来る」。船を出した者も、山にいる者も、寝ている者も、備える機会を失う。

辺境の集落に、角笛が盗まれたという噂が届く。噂を運んできたのは、名を告げない使者だった。

## 導入

冬の集落、長屋の火のそば。使者と名乗る旅装の男が、雪を落としながら角笛の一件を告げる。男は誰にも頼まない。ただ「知らせておく」と言って、次にどこへ行くかも言わずに座っている。

## 章1: 噂と足取り

- 角笛が消えたのは十四日前。虹の橋の見える岬では、その晩に橋が一度も光らなかったという証言が取れる
- 足取りは内陸へ向かっている。運んだ者は馬を使わず、歩き、盗品を隠す素振りもない。急いでいないのが不気味である
- 分岐条件: `flags.heard_the_rumor == true` → 使者の話を最後まで聞いたPCは、盗人が「神の敵ではないらしい」という一点を先に掴める

## 章2: 泉での視

- 世界樹の根に近い泉に、盗人の足跡が着いて、そこで途絶えている
- 泉を覗いた者は視る。映るのは盗人の姿ではなく、角笛が鳴らないまま終わりが来る朝の光景である
- 分岐条件: `flags.saw_the_vision == true` → 視た内容から盗人の居場所と動機が読み取れる。ただし泉は「視た者自身に関わる一場面」を必ず一つ混ぜてくる

## 章3: 返すか、鳴らないままにするか

- 角笛を橋のたもとへ返せば、終わりは予告付きで来る。人々は備えられるが、その日から全員が待つことになる
- 返さなければ、終わりは静かなまま近づく。誰も怯えずに済むかわりに、誰も間に合わない
- 誓いを立てる石の前でこの選択を口にした場合、それは取り消せない誓いになる。石を避けて決めることもできる

## GM専用情報

- **角笛を盗んだのは神々の敵ではない。** 終わりを一日でも先延ばしにしたかった人間である。角笛が鳴らなければ終わりも来ないと本気で信じており、いま角笛を抱えたまま、鳴らない世界がどこまで続くか確かめている
- **使者を名乗る者はロキの手の者だが、嘘は一つもついていない。** 語ることはすべて事実であり、事実だけを選んで並べることでPCを望む方向へ動かす。矛盾を突こうとしても矛盾は出てこない
- **隻眼の旅人はオーディンである。** PCが角笛をどうするかを見に来ているだけで、助言も妨害もしない。正体を看破されても認めも否定もせず、話題を変える
- 開示の順序: 章1で盗人が神の敵でないこと、章2で盗人の動機、章3で初めて使者と旅人のどちらか(あるいは両方)の素性
- 判定の見どころ: 使者の言葉の「選ばれ方」を見抜く / 泉を覗く覚悟(視たものは外れない)/ 盗人を説き伏せる交渉 / 誓いの石の前で言葉を選ぶ場面
