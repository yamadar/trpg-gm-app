# 画面・ナビゲーション

## グローバル画面

- **ホーム**: ソロ／Party セッションの開始・再開、スターター、次章開始
- **素材**: World、Character、Scenario、Ruleset、Campaign の作成・編集・再利用
- **さがす**: スターターと公開コンテンツの閲覧・取り込み
- **記録**: エンディング図鑑と実績
- **ユーザーページ**: 公開プロフィールと公開済みコンテンツ

URL は hash ルーティング。正規形は `#/library/...`、`#/browse/...`、`#/records/...`、`#/u/:userId/...`、`#/play/:sessionId`、`#/party/:sessionId` を使う。旧 `#/endings` と `#/achievements` は記録画面へ読み替える。

## 集中画面

セットアップ、ソロプレイ、Party 作成・参加・プレイは集中モード。グローバルナビを隠し、専用ヘッダーと終了導線を表示する。

ソロのセットアップは World、PC、Scenario、Ruleset を選択または新規作成し、セッション用スナップショットを作る。Campaign とスターターから受け取った文脈にも対応する。

## プレイ表示

- GM の地の文、選択肢、自由入力、判定結果、セッションログを表示する
- 緊張度 `low`／`medium`／`high` は文字送り速度と演出へ反映する
- Ruleset がリソースを持つ場合は現在値を表示する
- 終了状態ではエンディング確定と継続・記録作成の導線を出す
- 画像生成が有効なときは GM ログごとに場面挿絵を扱う

Party では参加者ごとに許可された描写、Fact、選択肢だけを表示する。生成時に全PC分の独立した物語を必須とする。共通の旅の目的と本人の個人目的を提示し、自分のキャラクターシート・リソース・状態・関係を開いて参照できる。

GMの進行段階、経過時間、失敗時の問い合わせIDは最新の文章の下に表示する。「最新の場面へ」で長いログの末尾へ移動できる。PC表示は物語の後に行動入力を置き、スマホは物語・行動・Partyの切替を使う。無制限時にはカウントダウンを表示せず、残り時間も分単位の目安にする。生成中に0秒を表示しない。

状態同期はチャット取得から独立し、古いイベント番号の応答では状態を巻き戻さない。フェーズ競合時は状態を再取得し、未送信の下書きを保持する。

Party作成・招待・プレイのヘッダーにログイン導線を置く。招待画面は未ログインなら「ログインして参加」を表示し、OAuth完了後に元の招待URLへ戻る。
