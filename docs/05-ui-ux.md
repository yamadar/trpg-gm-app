# 画面・ナビゲーション

## グローバル画面

- **ホーム**: ソロ／Party セッションの開始・再開、スターター、次章開始
- **素材**: World、Character、Scenario、Ruleset、Campaign の作成・編集・再利用
- **さがす**: スターターと公開コンテンツの閲覧・取り込み
- **記録**: エンディング図鑑と実績
- **ユーザーページ**: 公開プロフィールと公開済みコンテンツ

URL は hash ルーティング。正規形は `#/library/...`、`#/browse/...`、`#/records/...`、`#/u/:userId/...`、`#/play/:sessionId`、`#/party/:sessionId` を使う。旧 `#/endings` と `#/achievements` は記録画面へ読み替える。

## 集中画面

セットアップ、ソロプレイ、Party 作成・参加・プレイは集中モード。グローバルナビを隠し、専用ヘッダーと終了導線を表示する。

ソロのセットアップは World、PC、Scenario、Ruleset を選択または新規作成し、セッション用スナップショットを作る。Campaign とスターターから受け取った文脈にも対応する。

## プレイ表示

- GM の地の文、選択肢、自由入力、判定結果、セッションログを表示する
- 緊張度 `low`／`medium`／`high` は文字送り速度と演出へ反映する
- Ruleset がリソースを持つ場合は現在値を表示する
- 終了状態ではエンディング確定と継続・記録作成の導線を出す
- ソロセッションの挿絵は「挿絵の操作」を開くと「再生成…」「破棄…」が現れ、確認画面を経て操作する。処理中の表示はメニューを閉じても見え、通常の生成中表示と同じ文字サイズを使う。確認画面はキャンセルへ初期フォーカスを置き、Escapeでも閉じられる。処理中は画像操作の重複を防ぐ。再生成は利用枠を消費し、生成失敗時は元の画像を保持する。破棄は本文を残し、同じ画像を参照する小説からも画像を外す。
- 画像生成が有効なときは GM ログごとに場面挿絵を扱う

Party では参加者ごとに許可された描写、Fact、選択肢だけを表示する。生成時に全PC分の独立した物語を必須とする。共通の旅の目的と本人の個人目的を提示し、自分のキャラクターシート・リソース・状態・関係を開いて参照できる。

GMの進行段階、経過時間、失敗時の問い合わせIDは最新の文章の下に表示する。「最新の場面へ」で長いログの末尾へ移動できる。PC表示は物語の後に行動入力を置き、スマホは物語・行動・Partyの切替を使う。無制限時にはカウントダウンを表示せず、残り時間も分単位の目安にする。生成中に0秒を表示しない。

GM本文は左罫線を使わず、見出し・行間・上下の余白で読みやすく区切る。解決済みのPC行動は対応するGM描写の前に紙色のカードとして表示し、PC名と自動行動の区別を付ける。行動履歴はサーバーに保存し、従来のセッションでは保存済みラウンドから復元する。

スマホは新しいGM描写の到着時に物語タブを開き、最新の描写の冒頭へ移動する。通常の状態更新ではタブを切り替えない。手動切替ではタブごとのスクロール位置を復元し、物語末尾の「行動を選ぶ」から入力へ進める。下部操作には端末のセーフエリアと本文の余白を確保する。

状態同期はチャット取得から独立し、古いイベント番号の応答では状態を巻き戻さない。フェーズ競合時は状態を再取得し、同じラウンド内では未送信の下書きを保持する。次のラウンドへ進んだら、前ラウンドの入力は未送信の編集も含めてクリアする。再接続時は現在のラウンドで共有済みの行動を復元する。

Party作成・招待・プレイのヘッダーにログイン導線を置く。招待画面は未ログインなら「ログインして参加」を表示し、OAuth完了後に元の招待URLへ戻る。

## 読み込みと定期更新

画面はReact.lazy/Suspenseで遅延読み込みし、ライブラリのエディター等をホームの初期読み込みから外す。画面ロード中は読み込み表示を出す。

Party画面は表示中1秒間隔、非表示中15秒間隔で状態とチャットを取得し、再表示時に即時更新する。snapshotの`version`を次回の`known`へ渡し、表示対象の内容が変わらない場合は`unchanged`とサーバー時刻だけを返す。versionは参加者への投影全体から作るため、状態リビジョン以外の接続・typingの変化も反映する。時計は独立コンポーネントで1秒更新し、非表示中は描画更新を止める。
